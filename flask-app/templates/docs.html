API Documentation & Integration Guide

Welcome to the Technology Innovision WhatsApp Enterprise API Gateway. Connect multiple WhatsApp numbers, send high-deliverability messages with Anti-Ban simulation, and receive real-time webhooks.

Base Server URL

https://your-domain.com/api/v1 Production Endpoint

All API endpoints are relative to /api/v1/. For local development, use http://localhost:5000/api/v1.

Authentication

Every API request must include your secret API Key. You can find or regenerate your API Key in your Dashboard Settings.

Accepted HTTP Headers:

X-API-Key: your_secret_api_key_here
Authorization: Bearer your_secret_api_key_here

WhatsApp Account ID (account_id)

Every REST API request requires an account_id parameter. This identifies which connected WhatsApp number will dispatch the message. The API automatically accepts either the account alias (e.g. fahadstyles), the database integer ID (e.g. 1), or the internal session ID.

POST /api/v1/send

Universal / Legacy Endpoint

Sends a message to a single number, a comma-separated list, or an array of numbers. Features automatic Anti-Ban queuing and Spintax support.

<?php
$apiKey = "YOUR_API_KEY";
$apiUrl = "https://wpapp.tistack.online/api/v1/send";

$payload = [
    "account_id" => "fahadstyles",
    "to"         => "923001234567", // single number or "923001234567, 923119876543"
    "message"    => "{Hello|Hi} customer! Your order is on the way."
];

$ch = curl_init($apiUrl);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($payload));
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    "Content-Type: application/json",
    "X-API-Key: " . $apiKey
]);

$response = curl_exec($ch);
curl_close($ch);

$result = json_decode($response, true);
if ($result['status'] === 'success') {
    echo "Message sent successfully! Total: " . $result['total'];
}
?>
<?php
// Perfect for WooCommerce functions.php or WordPress plugins
function send_whatsapp_notification($phoneNumber, $messageText) {
    $apiKey = "YOUR_API_KEY";
    $apiUrl = "https://wpapp.tistack.online/api/v1/send";

    $response = wp_remote_post($apiUrl, [
        'headers' => [
            'Content-Type' => 'application/json',
            'X-API-Key'    => $apiKey,
        ],
        'body'    => wp_json_encode([
            'account_id' => 'fahadstyles',
            'to'         => $phoneNumber,
            'message'    => $messageText
        ]),
        'timeout' => 20
    ]);

    if (is_wp_error($response)) {
        error_log('WhatsApp send error: ' . $response->get_error_message());
        return false;
    }

    $body = json_decode(wp_remote_retrieve_body($response), true);
    return ($body['status'] === 'success');
}

POST /api/v1/send/buttons

✨ Click-To-Action (CTA) Buttons

Send WhatsApp business-grade interactive messages with clickable buttons attached. Also supported directly via the universal POST /api/v1/send endpoint by passing a "buttons" array!

1. Website Link Button

type: "url" — Opens website or product URL.

2. Direct Call Button

type: "call" — Directly dials support phone number.

3. Copy Code Button

type: "copy" — Copies promo coupon or order ID.

type: "quick_reply" — Taps button and gateway automatically replies back with your configured "reply": "..." message!

Anti-Ban Best Practices & Spintax Guide

Meta uses AI to detect automated bots on WhatsApp. Follow these four golden rules to ensure your WhatsApp accounts are never banned:

1. Always Use Spintax

Never send 100 identical messages. Use {Hello|Hi|Greetings} {friend|customer} so every dispatched message has a unique cryptographic hash.

2. Don't Blast Instant Bursts

Our platform automatically enqueues messages with randomized 4s–10s jitter delays. Never bypass the queue by firing 50 simultaneous parallel threads.

3. Warm Up Fresh Numbers

If you connected a brand-new SIM, start with 30 messages on Day 1, 60 on Day 2, and 120 on Day 3. Our Warm-Up schedule enforces this automatically.

4. Dedicated Session Proxies

If you manage 5+ accounts on one VPS, assign a residential or static HTTP/SOCKS5 proxy to each session in the Account Cockpit to isolate IP footprints.

Incoming Webhooks & Callbacks

Receive real-time HTTP POST notifications whenever an incoming WhatsApp message arrives or when a delivery status updates.

Sample Webhook Payload:

{
  "event": "message.received",
  "timestamp": "2026-09-11T05:30:15Z",
  "data": {
    "sessionId": "fahadstyles",
    "messageId": "3EB09F8421...",
    "from": "923001234567@s.whatsapp.net",
    "phone": "923001234567",
    "pushName": "John Doe",
    "type": "text",
    "body": "Hello, I would like to know the status of my order."
  }
}

If a Webhook Secret is configured in .env or session settings, the payload will include an HMAC SHA-256 signature in the X-Hub-Signature-256 header.
